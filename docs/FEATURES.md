# Current feature inventory

- Photography workspace with P / A / S / M exposure selection.
- Portrait, landscape, night, and sports starting programs that recall a suitable exposure and supported tone look.
- Six representative Sony α, Canon EOS R, Nikon Z, Fujifilm X, Panasonic LUMIX, and OM SYSTEM body profiles, each with its own picture-style menu and sensor-format preset.
- Profile-specific dual-native ISO on the LUMIX S5IIX, high-ISO noise reduction, supported soft-skin controls, and fill / slow-sync / rear-curtain flash looks.
- Aperture, shutter, ISO, exposure-compensation, lens, crop, sensor, metering, and white-balance controls.
- Three local photographic practice scenes, focus-point feedback, exposure indication, image-luminance histogram, and WebGL scenes with separately lit, locally bundled PBR models.
- Local photo import and opt-in camera access.
- Capture review, on-device library, edit panel, six color looks, basic tone controls, image download, and settings JSON import / export.
- Responsive Traditional Chinese / English / Japanese interface.
- Static GitHub Pages build, cacheable app shell and bundled scene photography, plus an optional progress-controlled offline pack for the 3D backplates, models, and textures.

Brand names and camera-style names identify the represented families. Colour, noise, skin, and flash outputs are software approximations, not exact proprietary camera processing; uploaded and webcam controls do not alter camera hardware or recover scene depth. See [body profile notes](CAMERA-PROFILES.md).

The 3D source layers modeled PBR props over local photographic environment plates and renders aperture / focus based Bokeh depth blur. The full environments are not modeled yet. Built-in 2D scenes use separately rendered foreground subjects over photographic backplates. Uploaded and webcam depth of field remains a software effect.
