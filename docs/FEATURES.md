# Current feature inventory

- Photography workspace with P / A / S / M exposure selection.
- Aperture, shutter, ISO, exposure-compensation, lens, crop, sensor, metering, and white-balance controls.
- Three local photographic practice scenes, focus-point feedback, exposure indication, image-luminance histogram, and WebGL scenes with separately lit, locally bundled PBR models.
- Local photo import and opt-in camera access.
- Capture review, on-device library, edit panel, six color looks, basic tone controls, image download, and settings JSON import / export.
- Responsive Traditional Chinese / English / Japanese interface.
- Static GitHub Pages build, cacheable app shell and bundled scene photography, plus an optional progress-controlled offline pack for the 3D backplates, models, and textures.

The 3D source layers modeled PBR props over local photographic environment plates and renders aperture / focus based Bokeh depth blur. The full environments are not modeled yet. Built-in 2D scenes are photographs rather than separately authored depth layers. Uploaded and webcam depth of field remains a software effect.
