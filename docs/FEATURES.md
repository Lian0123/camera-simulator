# Current feature inventory

- Photography workspace with P / A / S / M exposure selection.
- Aperture, shutter, ISO, exposure-compensation, lens, crop, sensor, metering, and white-balance controls.
- Three local photographic practice scenes, focus-point feedback, exposure indication, and image-luminance histogram.
- Local photo import and opt-in camera access.
- Capture review, on-device library, edit panel, six color looks, basic tone controls, image download, and settings JSON import / export.
- Responsive Traditional Chinese / English / Japanese interface.
- Static GitHub Pages build, cacheable app shell and bundled scene photography.

The 3D source currently presents local photographic scene plates inside a WebGL camera view; it does not contain fully modeled, relightable 3D environments or machine-readable depth maps. Built-in 2D scenes are photographs rather than separately authored depth layers. Uploaded and webcam depth of field remains a software effect.
